# Project Specification

## Status

This document records the project contract and its implementation status. The first Pure U-Net baseline is implemented, the bounded local CPU and Colab GPU sanity tests have passed, and the first full 100-epoch experiment has been completed in Colab.

## Purpose

Project_ViL is an experimental and educational medical-image segmentation project intended to support a future PhD interview. It investigates feature-processing mechanisms within a lightweight 2D U-Net framework.

## Research question

> How does Vision-LSTM-based feature processing compare with CNN and Swin Transformer feature processing within a lightweight U-Net framework for 2D medical-image segmentation?

## Non-goals

The project does not claim:

- a novel architecture;
- state-of-the-art performance;
- that ViL is inherently better than Swin;
- that ViL is inherently faster or more efficient;
- general superiority across medical segmentation tasks.

## Primary dataset

- Dataset: Kvasir-SEG
- Task: binary 2D polyp segmentation
- Input: RGB endoscopy image
- Target: binary pixel-level mask
- Dataset acquisition: local `data/Kvasir-SEG/` copy verified
- Dataset split: frozen `data/splits/kvasir_seg_seed42_70_15_15.json` with 700/150/150 pairs

## Planned model progression

1. Pure CNN U-Net baseline (completed).
2. Architecture A0: U-Net with a single-direction ViL/mLSTM bottleneck (completed and frozen).
3. Architecture A1: independent alternating/bidirectional ViL/mLSTM bottleneck ablation.
4. Optional A2: A1 with positional encoding.
5. Architecture B and later comparisons.

## Computational constraint

The project targets a basic laptop and Google Colab. The initial scope is lightweight 2D experimentation. 3D segmentation, full paper-scale pretraining, and large benchmark reproduction are explicitly deferred.

## Scientific philosophy

The project will use a common data and training protocol where practical, document unavoidable architecture-specific differences, measure computation rather than assume it, and restrict conclusions to the evaluated dataset and experiments.

## Baseline implementation status

- Configuration: `configs/baseline_pure_unet.json`
- Sanity configuration: `configs/sanity_pure_unet.json`
- Mask preprocessing: grayscale, `gray >= 128`, binary conversion, then nearest-neighbor resize; 128 is an engineering choice, not an official dataset threshold.
- Local development runtime: Python 3.12.13 with PyTorch 2.6.0+cpu; bounded CPU sanity test passed.
- Colab experiment runtime: Python 3.13.15 with PyTorch 2.11.0+cu128 and CUDA 12.8 on an NVIDIA Tesla T4 with 15.6 GB GPU memory; bounded CUDA sanity test passed.
- Full 100-epoch Colab training: completed; best validation-Dice checkpoint was epoch 40.
- Best validation Dice: `0.828427411334084`; final test Dice: `0.8241105952570058`; final test IoU: `0.7412125480073589`.
- Qualitative analysis: completed post-hoc using a deterministic fixed sample and the four lowest-Dice test cases; the artifacts are generated by `scripts/visualize_predictions.py`.
- Architecture A0: corrected project-local Pure U-Net + single-direction ViL/mLSTM bottleneck completed and frozen; best validation-Dice checkpoint was epoch 51.
- Architecture A1: current independent alternating/bidirectional traversal ablation; implementation and bounded CPU sanity validation passed, but the first full run failed at epoch 27 and is not a valid result. A bounded A0/A1 activation-amplification diagnostic completed without non-finite values, but did not reproduce or localize the original failure; no architecture or protocol change has been made.
- Forensic A1 tooling: the first diagnostic continuation used level-triggered warning checkpointing, which produced repeated checkpoint writes during sustained threshold violations. This was corrected in `scripts/train_a1_forensic.py` with edge-triggered warning episodes, retained failure checkpoints, and a default 10-epoch regular-checkpoint interval. This is a diagnostic storage correction only; the historical run, A1 implementation, and scientific protocol remain unchanged.

Local CPU debugging and Colab GPU experimentation remain separate execution environments. The Pure U-Net baseline and A0 are frozen. A1 is the next controlled experiment; Architecture B is deferred until the traversal ablation is evaluated.

The supplied forensic archive recorded 172 warning events (143 training and 29 validation), with the first warning at epoch 1, training batch 165, in the forward ViL gated product. It contained no checkpoint files, and the supplied startup reproducibility state contained RNG state only. Consequently, the storage correction has been validated with bounded local tests but does not reproduce or localize the original epoch-27 A1 failure.
